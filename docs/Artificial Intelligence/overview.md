## How to read this

- **Content** folders have real articles (sourced, with diagrams/tables) — start there.
- **Skeleton** folders have only an `overview.md` with the roadmap bullets for that topic, waiting to be expanded into full articles the same way `RAG Architecture` and `Pretraining vs fine-tuning vs RLHF` were written.
- [`Questions`](./Questions.md) is a running interview-prep question bank, not tied to any one folder.

## Suggested order

Foundations → LLM Application Development → Large Language Models (internals) → RAG → Agents and Orchestration → Evaluation and Observability → Fine-Tuning and Model Adaptation → Deployment and LLMOps → Security and Governance → Architect-Level Systems and Strategy → Forward Deployed Engineering.
